# Информационная система кинотеатра

Готовый учебный проект на Flask и SQLite: публичная афиша, регистрация покупателей, интерактивная схема зала, бронирование, личный кабинет, администрирование и отчётность.

## Возможности

### Покупатель

- современный адаптивный интерфейс с JavaScript-анимациями;
- светлая, тёмная и системная темы с сохранением выбора;
- четыре цветовых акцента интерфейса;
- просмотр и поиск фильмов без регистрации;
- фильтр расписания по дате;
- регистрация и безопасная авторизация;
- выбор до 10 мест на интерактивной схеме;
- защита от одновременного бронирования одного места;
- личный кабинет с действующими билетами;
- отмена неоплаченной брони до начала сеанса;
- изменение пароля.

### Администратор

- управление пользователями, ролями и контактами;
- блокировка, разблокировка, удаление и сброс пароля пользователя;
- защита от блокировки собственной записи и последнего администратора;
- управление фильмами и залами;
- создание, изменение и удаление сеансов;
- проверка пересечения сеансов в одном зале;
- поиск билетов по покупателю или фильму;
- подтверждение оплаты и отмена брони;
- отчёты по заполняемости и выручке за период;
- резервное копирование базы данных.

### Безопасность и надёжность

- пароли хранятся в виде хэшей Werkzeug;
- все изменяющие запросы защищены CSRF-токеном;
- SQL-запросы параметризованы;
- доступ администратора проверяется на сервере;
- активное место защищено уникальным индексом SQLite;
- бронирование выполняется в транзакции `BEGIN IMMEDIATE`;
- отменённая бронь скрывается из кабинета, но сохраняется для аудита;
- файловое логирование с ротацией находится в `instance/logs`;
- служебный маршрут `/health` проверяет работоспособность приложения.

## Запуск в PyCharm на CachyOS

1. Распакуйте архив и откройте папку `cinema_site` через **File → Open**.
2. В PyCharm выберите **Settings → Project → Python Interpreter → Add Interpreter → Virtualenv**.
3. В терминале PyCharm выполните:

```bash
pip install -r requirements.txt
python app.py
```

4. Откройте в браузере:

```text
http://127.0.0.1:5000
```

База `instance/cinema.db` и демонстрационные записи создаются автоматически.

## Администратор

```text
Логин: admin
Пароль: Admin123!
```

Сразу после первого входа измените пароль в разделе **Мои билеты / Настройки аккаунта**. Для администратора ссылка ведёт в панель управления, но страницу профиля можно открыть по адресу `/profile`.

## Структура проекта

```text
cinema_site/
├── app.py                    # фабрика приложения и общая конфигурация
├── database.py               # подключение SQLite
├── schema.sql                # таблицы, индексы и ограничения
├── seed.py                   # демонстрационные данные
├── utils.py                  # декораторы авторизации
├── routes/
│   ├── main.py               # афиша и поиск
│   ├── auth.py               # регистрация, вход и пароль
│   ├── booking.py            # бронирование и личный кабинет
│   └── admin.py              # административные операции
├── services/
│   └── maintenance.py        # логирование и резервные копии
├── templates/                # HTML-шаблоны Jinja2
├── static/style.css          # адаптивный интерфейс и темы
├── static/app.js             # тема, интерактивность и анимации
└── tests/test_smoke.py       # базовые автоматические проверки
```

## Резервное копирование

```bash
flask --app app backup-db
```

Копия появится в `instance/backups`. Другой каталог можно указать явно:

```bash
flask --app app backup-db --output ~/cinema-backups
```

## Тестирование

```bash
python -m unittest discover -s tests -v
```

## Запуск через Waitress

Для локальной сети вместо отладочного сервера Flask:

```bash
waitress-serve --host=0.0.0.0 --port=5000 app:app
```

Не публикуйте сайт в интернете без HTTPS, смены стандартного пароля и установки собственного значения `SECRET_KEY`.
